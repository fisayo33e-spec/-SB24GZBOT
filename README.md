# EduAssistBot 🤖📚

An educational Telegram bot built with Python and deployed on Railway.

## Features
- `/start` — Welcome message
- `/help` — Command list
- `/quiz` — Random quiz question
- `/answer <text>` — Submit your answer
- `/calc <expression>` — Safe math calculator
- Echo handler for any other text
